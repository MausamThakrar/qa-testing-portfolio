# QA Testing Portfolio

This repository contains practical software testing work samples, including manual testing documentation, test cases, bug reports, API testing, SQL validation, and automation testing practice.

## Skills Demonstrated

- Requirement analysis
- Test scenario design
- Test case writing
- Bug reporting
- Functional testing
- Regression testing
- UI testing
- API testing using Postman
- Basic SQL validation
- Automation testing basics using Playwright
- Test summary reporting

## Portfolio Structure

| Area | Description |
|---|---|
| Manual Testing | Test plans, scenarios, test cases, bug reports, and summary reports |
| API Testing | Postman collections, API test cases, and API test summaries |
| SQL Testing | SQL queries and database validation examples |
| Automation Testing | Basic Playwright automation scripts and reports |

## Sample Projects

### 1. Registration Form Testing
Manual testing documentation for a user registration feature, including positive, negative, boundary, and validation scenarios.

### 2. Login Page Testing
Functional and negative testing documentation for a login feature.

### 3. API Testing
API testing examples using Postman with request validation, status code checks, and response verification.

### 4. Automation Testing
Basic UI automation examples using Playwright.

## Goal

To demonstrate practical QA skills through clear, structured, and job-relevant testing artifacts.
